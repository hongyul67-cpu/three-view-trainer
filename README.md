# 📐 3면도 트레이너 — 정투상 도형 실습

**기초제도 Ⅲ. 제도의 기본 도법 — 2. 정투상도 그리기** 단원의 **도형 실습**용 도구입니다.
용어·투상법 종류(정투상/등각/사/투시) 개념은 [투상도 마스터(개념편)](https://hongyul67-cpu.github.io/tusang-master/)에서 먼저 익히고,
이 도구로 **3면도 ↔ 입체를 서로 변환하는 실습**을 합니다.
설치 없이 브라우저에서 바로 실행되며, HTML 파일 하나로 오프라인·휴대폰에서도 작동합니다.

## 왜 만들었나

교과서 대단원 평가에서 가장 많이 나오는 유형이 **① 3면도를 보고 입체 고르기**, **② 입체를 보고 투상도 고르기** 인데,
이 부분은 말로 설명하기 어렵고 학생이 스스로 확인해 볼 방법이 마땅치 않습니다.
이 도구는 입체를 무작위로 만들어 **3면도를 실시간으로 그려 주고**, 같은 원리로 문제를 무한히 출제합니다.

## 구성

| 모드 | 내용 | 대응 단원 |
|------|------|-----------|
| 📖 **배우기** | 입체와 3면도를 나란히 보여 주고, 연결선으로 **치수 공유 관계**를 시각화. 제3각법↔제1각법 배치 비교 | Ⅲ-2 |
| **도전 ①** 도면→입체 | 3면도를 보고 입체(등각투상도) 고르기 | 교과서 평가 02번 유형 |
| **도전 ②** 입체→투상도 | 입체를 보고 정면도·평면도·우측면도 중 하나 고르기 | 교과서 평가 03번 유형 |
| **도전 ③** 각법 구분 | 배치를 보고 제1각법·제3각법 판별 | Ⅲ-2 |
| 🎯 **종합시험** | 세 유형을 섞어 10문항 출제 후 **결과 제출** | 형성평가용 |

## 수업에서 쓰는 법

- **수업 자료**: `배우기` 탭을 화면에 띄우고 `🎲 다른 입체`를 누르며 설명. 연결선(주황 점선)으로 "정면도와 평면도는 너비가 같다"를 눈으로 보여 줄 수 있습니다.
- **각법 비교**: 제3각법↔제1각법 버튼으로 배치가 위아래·좌우로 뒤집히는 것을 즉시 대조.
- **형성평가(제출)**: 주소 뒤에 `?rc=<Apps Script URL>` 를 붙여 배포하면, 종합시험 종료 시 학생이 **반·번호**를 넣어 제출하고 결과가 구글 시트에 모입니다.
  ```
  .../투상도-master/?rc=https://script.google.com/macros/s/.../exec
  ```

## 도면 표기

실제 제도 규칙을 따릅니다.

- **외형선** — 보이는 모서리 (굵은 실선)
- **숨은선** — 가려져 보이지 않는 모서리 (파선). 앞쪽이 높고 뒤쪽이 낮을 때 나타납니다.
- **연결선** — 투상도끼리 치수가 정렬됨을 보여 주는 보조선 (주황 점선, 학습용)
- 제3각법이 KS 표준이며, 기본값입니다.
